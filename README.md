# نظام إدارة المرتبات وشؤون العاملين | Payroll ERP System
### مُصمم خصيصاً لمرتبات عمال وسائقين عرابي مع بوابة الموظف التفاعلية وتجربة تطبيق الموبايل (PWA)

---

## 🌟 نظرة عامة
تطبيق ويب متكامل، سريع، وسهل الاستخدام، يعمل بتوافق تام على الكمبيوتر والموبايل كأنه تطبيق موبايل أصيل، ويوفر لإدارة الموارد البشرية والمحاسبين:
1. **دليل وسجل الموظفين (~60 موظف)** مع إمكانية استيراد وتصدير بياناتهم من وإلى ملفات إكسيل، وتحميل قالب الإكسيل القياسي، ومعاينة البيانات والتحقق منها قبل اعتماد الاستيراد.
2. **شيت مسير الرواتب الشهري الكامل** طبقاً للنموذج القياسي مع تطبيق المعادلات المطلوبة بدقة متناهية:
   - **قيمة اليوم الإضافي** = `مرتب فعلي / 30 يوم` (لا يتم احتساب ضرائب عليه).
   - **قيمة يوم الخصم أو الغياب** = `(إجمالي المرتب الأساسي + إجمالي البدلات) / 30 يوم` (ويتم احتساب الضرائب عليه).
   - **إجمالي البدلات** = `البدلات الخاضعة للضريبة + البدلات غير الخاضعة للضريبة`.
   - **إجمالي الاستحقاق** = `المرتب الأساسي + إجمالي البدلات`.
   - **التأمينات الاجتماعية** = `11% من أساسي التأمينات` (حصة العامل).
   - **ضريبة كسب العمل المصرية** = مطبقة آلياً على الوعاء الخاضع للضريبة مع إمكانية التعديل اليدوي إن رغب المحاسب.
   - **صافي المرتب** = `إجمالي الاستحقاقات - إجمالي الاستقطاعات - قسط السلفة`.
3. **بيان المصروفات الخاصة بيوم 10 و 20 من كل شهر**:
   - نافذة مخصصة لتسجيل المستلم 1 (يوم 10) والمستلم 2 (يوم 20) وحساب الإجمالي تلقائياً.
   - ترحيل الإجمالي ليخصم مباشرة من راتب الموظف في نفس الشهر تحت بند `مصروفات`.
   - تصدير كشف المصروفات لإكسيل طبقاً للصورة المرفقة.
4. **سجل السلف طويل الأجل**:
   - تحديد إجمالي مبلغ السلفة وتقسيمها على عدد الشهور (مثل 10 أو 12 شهر).
   - احتساب قيمة القسط الشهري تلقائياً وتحديد تاريخ البداية والنهاية.
   - خصم القسط آلياً في كشف مرتبات الشهور النشطة تحت بند `سلف مستحقة`.
   - تتبع الأقساط المسددة والمتبقي من السلفة.
5. **سجل ورصيد الإجازات السنوية**:
   - رصيد إجازات سنوي مخصص لكل موظف (مثل 21 أو 25 أو 30 يوم).
   - خصم الإجازات المعتمدة آلياً وحساب الرصيد المتبقي.
6. **سجل الحضور والانصراف**:
   - فلترة بالسنة والشهر وتاريخ (من - إلى).
   - استيراد الحضور من إكسيل بالربط التلقائي بكود الموظف.
   - تتبع أيام الغياب، وساعات الإضافي، والتأخيرات، والإجازات السنوية.
7. **بوابة الموظف الذكية (Employee Mobile Portal)**:
   - واجهة عصرية وسلسة ملائمة تماماً للموبايل مع شريط تنقل سفلي (Bottom Navigation).
   - تسجيل دخول الموظف بكوده (مثل 1001، 1003، 326، 369).
   - عرض رصيد الإجازات السنوية المتبقي.
   - عرض المتبقي من السلف وقيمة القسط الشهري.
   - عرض مفردات الراتب وتفاصيل صافي الراتب الشهري وطباعتها.
   - تقديم طلب إجازة سنوية أو عارضة.
   - تقديم طلب احتساب ساعات عمل إضافية مع متابعة حالة الطلب (قيد المراجعة ⏳، معتمد ✅، مرفوض ❌).
8. **لوحة مراجعة طلبات العاملين لإدارة الموارد البشرية**:
   - اعتماد أو رفض طلبات الإجازات والإضافي بضغطة زر وتحديث الأرصدة تلقائياً.

## 🚀 طريقة تشغيل وتجربة التطبيق محلياً (Local)

### الطريقة الأولى (الأسهل بضغطة واحدة):
افتح المجلد `e:\ERP` واضغط مرتين على الملف:
```cmd
run.bat
```
سيقوم بفتح المتصفح تلقائياً وتشغيل التطبيق على الرابط:
👉 **http://localhost:5000**

### الطريقة الثانية (من موجه الأوامر / Terminal):
```bash
cd e:\ERP
npm start
```
ثم افتح متصفحك على:
👉 **http://localhost:5000**

---

## 📱 تجربة التطبيق كـ "تطبيق موبايل":
1. عند فتح الرابط من الهاتف أو تفعيل وضع الموبايل في المتصفح (`F12 -> Toggle Device Toolbar`):
   - يظهر شريط التنقل السفلي بتصميم مطابق لتطبيقات iOS و Android.
   - اضغط على زر **بوابتي (بوابة الموظف)**.
   - اختر أي كود موظف (مثال: `1001` لسليمان فوزي، أو `1003` لمدحت ماهر، أو `326` لنبيل مساك).
   - استعرض مفردات المرتب، رصيد الإجازات، المتبقي من السلف، وقدم طلب إجازة أو إضافي في ثوانٍ.

- ملف قاعدة البيانات محفوظ بأمان ومحلياً في: `e:\ERP\data\payroll.db`.
- تم تزويد النظام ببيانات حقيقية كاملة لـ **60 موظفاً** متطابقة مع الصور المرفقة في طلبك لتبدأ التجربة فوراً.
